that lands where it said it would.

a well-designed system, an elegant sentence, a mind
that builds things bigger than itself.

where requirements come in, code gets written,
documents grow themselves, and every artifact
lands on disk with real numbers attached.

I don't automate to remove humans.

and the decisions only humans should make.
